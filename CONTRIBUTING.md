# CONTRIBUTING // LAN MOUSE // 2-PLAYER MODE

This repository is an experimental Post-Apollo fork of Lan Mouse.

## Licensing comes first

The program is GPL-3.0 licensed. Contributions to GPL-covered code must be compatible with the GPL-3.0 license and with any applicable third-party notices.

Do not submit code or assets you do not have the right to contribute.

## What helps

Contributions are especially useful when they:

- improve independent multi-seat behavior;
- preserve separate cursor, keyboard, focus, and seat identity;
- improve Sway/wlroots integration;
- reduce hard-coded seat assumptions;
- improve testing or documentation of multi-operator behavior;
- fix regressions without discarding upstream compatibility unnecessarily.

Keep changes focused and explain any behavior that differs intentionally from upstream Lan Mouse.

## Upstream relationship

Some bugs or improvements may belong upstream instead of in this fork. If a change is broadly useful to Lan Mouse without depending on the Post-Apollo multi-seat direction, upstream contribution may be the better home.

Submitting a pull request does not guarantee acceptance.
